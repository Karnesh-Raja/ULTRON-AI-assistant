# ULTRON User Guide

This folder is ULTRON's searchable project documentation. Add your own .md or .txt files here
(for example notes about your project, design decisions or API descriptions) and say
"search the docs for ..." to find them.

## Wake word

Press the WAKE WORD button (or the W key) once and allow the microphone. Then say "Hey ULTRON"
followed by your request, for example "Hey ULTRON, what time is it?". The orb turns cool blue
while it is listening. Wake word listening pauses while ULTRON speaks so it does not hear itself.
It needs Chrome or Edge, an internet connection, and the page must stay open.

## Built-in commands

ULTRON handles these itself without calling the AI:
time and date ("what time is it", "what is the date"), timers ("set a timer for five minutes"),
reminders ("remind me in ten minutes to call mom"), notes ("take a note: ..."), to-do lists
("add buy milk to my to-do list", "show my to-do list", "mark todo 2 as done"), opening approved
websites ("open YouTube"), web search ("search for python decorators on YouTube") and documentation
search ("search the docs for gestures").

## Orb states

Idle is the normal amber glow. Listening turns the orb a cool blue and makes it breathe slowly.
Thinking spins the orb quickly while the AI is working. Speaking pulses the core with each spoken
word. An error flashes the orb red. Paused dims the orb almost completely.

## Conversation memory

ULTRON remembers the current conversation, so follow-up questions work: after asking about Python
you can say "explain that with another example". The last twelve messages are sent to the AI.
The conversation history is saved in the browser and can be cleared by saying "clear history".

## Hand gestures

Turn on GESTURES with the G key. Pinch with one hand to spin the orb, pinch with both hands and
spread to zoom. Hold an open palm still for about one second to pause or resume ULTRON. Swipe an
open hand left to go to the next panel and right to go to the previous panel (Chat, Tasks, Docs).

## Keyboard shortcuts

G toggles hand gestures. W toggles the wake word. P pauses or resumes ULTRON. R resets the view.
Plus and minus zoom in and out.
